# Калькулятор личных финансов

Простое консольное приложение на Python для учета доходов и расходов.

## Описание
Приложение позволяет пользователю:
* Добавлять новые операции (доходы или расходы) с указанием суммы, категории и даты.
* Просматривать список всех сохраненных операций.
* Видеть текущий баланс (разница между доходами и расходами).
* Работать с приложением через простое интерактивное меню в консоли.

Данные сохраняются в локальном файле `operations.json`.
